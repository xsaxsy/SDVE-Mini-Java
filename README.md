# Sistema Digital de Votación Estudiantil (SDVE)

## Descripción

El Sistema Digital de Votación Estudiantil (SDVE) es una aplicación de escritorio desarrollada en C# mediante Windows Forms, cuyo objetivo es gestionar procesos de votación estudiantil de manera digital.

El sistema permitirá administrar convocatorias, candidatos, emisión de votos, resultados y exportación de información.

## Funcionalidades principales

* Gestión de convocatorias electorales.
* Registro y administración de candidatos.
* Selección de elecciones disponibles.
* Emisión de votos mediante una papeleta electrónica.
* Registro de candidatos no registrados (write-in).
* Validación de participación de los alumnos.
* Conteo y agregación de resultados.
* Consulta de resultados por grupo, carrera y centro universitario.
* Cálculo de participación y abstencionismo.
* Visualización gráfica de resultados.
* Exportación de resultados en formatos estructurados.
